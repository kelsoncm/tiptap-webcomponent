# Política de segurança

## Versões suportadas

Apenas a versão mais recente publicada no npm recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra issue pública. Use o [reporte privado de vulnerabilidades do GitHub](https://github.com/tiptap-by-kelsoncm/tiptap-webcomponent/security/advisories/new).
Inclua versão afetada, passos para reproduzir e impacto esperado. A resposta inicial ocorre em até 7 dias.
